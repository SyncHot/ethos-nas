# Music — Radio (web ↔ Android parity)

Web player must match the Android app 1:1 (see `AGENTS.md` → *Web ⇄ Android feature parity*).
The Android app had a **Radio** tab (`ethos-music/ui/screens/RadioScreen.kt`, catalog in
`RadioModels.kt`); the web Music app did not. This feature closes that gap.

## Plan / status

- [x] Shared station catalog: `backend/radio_stations.json` v2 — **150 Polish streams**
      (Publiczne / Komercyjne / Regionalne / Religijne / Muzyka), generated by
      `scripts/build_radio_catalog.py` — see `docs/music-catalogs.md`
- [x] API: `GET /api/music/radio/stations?q=&category=` →
      `{ categories: [...], stations: [{id, name, category, stream_url, tags, city, logo,
      codec, bitrate, hls, homepage, verified}], total, generated_at }`
      (auth via the standard token middleware; empty catalog + logged warning if the file is missing)
- [x] Web: **Radio** tab in `frontend/static/apps/music.js`
      - 6-item bottom nav (Start / Szukaj / Podcasty / **Radio** / Biblioteka / Ustawienia)
      - sections *Ulubione* and *Ostatnio słuchane* (synced with the NAS: `GET/PUT /api/music/radio/state`,
        `localStorage` stays as an offline cache)
      - search field (folded Polish characters) + category chips + station logos
      - tap = live playback (station URL played directly, no NAS proxy — same as Android)
      - full player shows `● NA ŻYWO` instead of the seek bar; radio is excluded from play history
- [x] Android: the app now fetches the same catalog (`CatalogStore`, assets as fallback),
      has station search, logos and shares favourites with the web
- [x] Verified: isolated instance → endpoint 200 with 150 stations, 6 categories;
      headless Playwright run renders 150 rows, filters to “Trójka”, no JS errors
- [x] “Teraz gra”: ICY (`StreamTitle`) dla MP3/AAC + ID3 (TIT2/TPE1) dla HLS w Androidzie
      (`playback/IcyMetadataDataSource.kt`, `playback/NowPlaying.kt`)
